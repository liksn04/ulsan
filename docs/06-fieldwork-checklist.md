# 06. 원자료 열람 및 현장 답사 체크리스트

## 자료 열람 시

- [ ] 열람기관 / 서지 / 보존번호 / 권·면 / 스캔 파일 ID 기록
- [ ] 인쇄본 쪽 번호와 PDF 페이지 번호 별도 기록
- [ ] 제작 시기·편찬 시기·후대 수정 시기 구분
- [ ] 지명 한글(원문)·한자(원문)·현대 독음을 각각 전사
- [ ] 같은 한자 표기라도 다른 장소인지 검토
- [ ] 위치·소속 행정구역·지번을 직독/추정으로 분류
- [ ] 원문 열람 근거 스크린샷/링크와 공개 가능 여부 기록
- [ ] 연구자의 추정·구술 전승은 원문 서술과 구분

## 답사 전

- [ ] 허가 없이 사유지·고고학 현장 출입 금지
- [ ] 물탕골·원내골·상아골 등의 지형 후보는 **확정 좌표로 안내하지 않음**
- [ ] 현대 정류장·도로명 주소의 실재/위치를 공식 DB와 대조
- [ ] 과거 항공사진·현대 하천/등고선을 준비
- [ ] 사진 GPS·촬영방향·관찰 시간 기록 및 사생활 노출 방지

## 주민 구술 시

- [ ] 목적·녹음 여부·공개 범위·철회 방법 사전 동의
- [ ] 생년·거주기간 등 민감·식별정보 최소화
- [ ] '어릴 때 부르던 이름', '지명 경계', '하천 이동', '기억나는 건물/바위'를 유도 없이 질문
- [ ] 제3자에 관한 신상정보 비공개
- [ ] 구술과 공적 문헌이 다른 경우 두 기록을 나란히 보존

## 한 장소의 기록 양식

```yaml
record_id: FIELD-YYYYMMDD-001
toponym_id: GUL-...
observed_at: YYYY-MM-DD
observer: anonymous-or-consented
location_basis: modern_landmark | parcel_history | relative_only | unknown
latitude: null
longitude: null
photo_ref: null
oral_history_consent: not_applicable
original_description: ""
interpretation: ""
source_ids: [SRC-001]
review_status: pending
```

현장기록과 연구 결과를 별도 관리하고, 근거 없는 좌표 보정이나 임의 동리 경계 그리기를 금한다.
