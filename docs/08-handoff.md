# 다음 조사 세션으로 이어가기 (Handoff)

2026-11-07 시점의 연구 맥락을 새 대화·다른 연구자가 재사용하기 위한 안내.

## 한 문장으로

울산 울주군 범서읍 굴화리의 역사와 옛 지명(굴아화·하곡·굴불·굴화), 1914년 통합 전 네 마을(굴화/장검/백천/괴정), 21 골짜기·8 들판·미연결 1911 인용 4개를 사료 대조와 역사 GIS로 복원한다.

## 지금까지 실제 수행한 것

- 기존 연속 대화를 기반으로 선사~현대 지역사, 어원, 자연마을, 역참과 역촌, 주변지역을 통합했다.
- 2018년 『울산군 골짜기와 들판』 PDF 인쇄본 pp.13–14를 실제 열람해 여러 전사 오기를 교정했다.
- 37개 지명(`data/toponyms.csv`), 4개 현대 기준점(`data/control_points.csv`), 12개 출처(`data/sources.csv`), 12개 주장(`data/claims.csv`)을 등록했다.
- 데이터 구조, 정정내역, 연구의 한계, 역사공간 복원 방법, 현장답사 규약, 단계별 로드맵을 문서화했다.
- Python 표준 라이브러리 기반 유효성검사/GeoJSON 생성기/단위 테스트/CI 설정을 올렸다.
- GitHub Issues #1~#5에 실제 후속 연구 작업을 분할했다.
- GitHub에 업로드된 CSV는 2026-11-07에 **행 수, 분류, 출처 ID 연결, 현대 좌표 대략 범위를 직접 검증**했다. Python 테스트의 CI 성공 여부는 별도 확인 필요.

## 미확정이라고 반드시 말해야 하는 내용

1. 1911년 『조선지지자료』 원본은 아직 판독하지 못했고, 2018년 편찬물의 재인용만 확인했다.
2. 1912~1918년 지적원도 원본 도엽이 없으므로 1911년 동리 경계는 복원하지 못했다.
3. 4개 현대 기준점은 옛 마을 중심점이 아니다. 물탕골 589-5와 백천2길 22-65의 정확한 지번 계보는 공식자료 미검증이다.
4. 굴아화현 관아, 굴화역 본건물, 굴화원 위치는 미확정이다.
5. 청동기 집자리 '87기 합산'은 이전 대화의 잠정 합계이고 최종 집계나 동시기 주택 수가 아니다.
6. 장검=장고암, 수정=괴정, 원내골=굴화원 등의 동일시 및 어원 설명은 검증 대상이다.

## 다음에 바로 할 작업

**Issue #1**: 1911 『조선지지자료』 울산군 범서면 구간을 확보하고 원본을 전사한다. 이후 `data/toponyms.csv`의 `quoted_1911_hanja`, `quoted_1911_village`를 1차 사료와 조목조목 대조한다.

**Issue #2**: 국가기록원 지적원도를 획득하고 도엽명·지번·권리정보를 정리한다. QGIS 등에서 제어점을 선택하고 오차 기록까지 남긴다.

**Issue #3**: 물탕골/배나무골/상아골/안골의 과거 지번과 현대 주소 관계를 공식 지적 자료로 검증한다.

후속 AI/연구자는 시작 전 `README.md`, `docs/01-research-context.md`, `docs/03-toponymy-and-errata.md`, `docs/04-georeferencing-method.md`, `AGENTS.md`를 반드시 읽는다. 사용자가 앞서 제공한 맥락을 되묻지 않고, 새로 확인한 자료와 이전 데이터 사이의 차이를 표로 남기고 수정한다.

## 간단 실행

```bash
git clone https://github.com/liksn04/ulsan.git
cd ulsan
python scripts/validate_data.py
python -m unittest discover -s tests -v
python scripts/export_geojson.py
```

정확한 연표/서지/한계는 [통합보고서](07-comprehensive-report.md)에서 확인한다.
