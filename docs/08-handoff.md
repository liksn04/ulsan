# 다음 조사 세션으로 이어가기 (Handoff)

2026-11-07 시점의 연구 맥락을 새 대화·다른 연구자가 재사용하기 위한 안내.

## 한 문장으로

울산 울주군 범서읍 굴화리의 역사와 옛 지명(굴아화·하곡·굴불·굴화), 1914년 통합 전 네 마을(굴화/장검/백천/괴정), 21 골짜기·8 들판·미연결 1911 인용 4개를 사료 대조와 역사 GIS로 복원한다.

## 미확정이라고 반드시 말해야 하는 내용

1. 1911년 『조선지지자료』 원본은 아직 판독하지 못했고, 2018년 편찬물의 재인용만 확인했다.
2. 1912~1918년 지적원도 원본 도엽이 없으므로 1911년 동리 경계는 복원하지 못했다.
3. 4개 현대 기준점은 옛 마을 중심점이 아니다. 물탕골 589-5와 백천2길 22-65의 정확한 지번 계보는 공식자료 미검증이다.
4. 굴아화현 관아, 굴화역 본건물, 굴화원 위치는 미확정이다.
5. 청동기 집자리 '87기 합산'은 이전 대화의 잠정 합계이고 최종 집계나 동시기 주택 수가 아니다.
6. 장검=장고암, 수정=괴정, 원내골=굴화원 등의 동일시 및 어원 설명은 검증 대상이다.

## 간단 실행

```bash
git clone https://github.com/liksn04/ulsan.git
cd ulsan
python scripts/validate_data.py
python -m unittest discover -s tests -v
python scripts/export_geojson.py
```
