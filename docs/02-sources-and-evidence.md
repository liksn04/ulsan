## 조사철(docs/09)에서 옮긴 미대조 출처

PR #7 조사철이 언급한 자료를 SRC-013~SRC-026으로 등록했다. 모두 `citation_identified`(서지만 확인 대상으로 올림) 또는 `needs_official_recheck`이며, 열람본·면수·열람일이 기록될 때까지 원문 구절을 사실로 인용하지 않는다.

- **SRC-013** 『신증동국여지승람』 권22 울산군 역원·산천 조(1530) — 굴화역·굴화원·굴화천 구절(CL-013, CL-014)

- **SRC-018~SRC-024** 굴화리 일대 발굴조사보고서 7권(2002~2012) — 서지·지번·유구 수 확인 필요(CL-020)

- **SRC-026** parcels_research.csv 좌표의 민간 지도 조회 결과 — 공식 재조회 필요(CL-021)

## 증거상태 필드

- `source_verified`: 직접 확인한 공개 문헌의 내용(이것이 역사적 사실의 최종 확정과 같지는 않음).
- `secondary_quote`: 원전의 2차 인용, 직접 대조 미완료.
- `hypothesis`: 어원, 위치, 전승의 해석과 비정.
- `pending`: 개별 주장/좌표의 검증 대기.
- `disputed`: 근거가 없거나 등록된 출처와 충돌하는 주장. 충돌 내용을 `next_check`에 적고, 근거가 확보될 때까지 인용하지 않는다.
- `rejected`: 반증·오기로 판정, 별도 정정 사유 필요.

## 인용 관행

각 지명의 표제어는 SRC-001 pp. 13–14를 기본 출처로 삼는다. 1911년 표기란에도 **“SRC-001이 인용한 SRC-008의 표기”**라는 provenance를 붙인다. 2024 논문의 초록을 보고 역촌을 비정할 수는 있지만, 초록만으로 연구자의 원도·도면을 실제 검증한 것처럼 쓰지 않는다.

원문 사진·고지도는 출처/소장처/열람일/이용조건을 따로 관리한다. 원문 파일은 저작권과 기관 이용규정 확인 전까지 이 저장소에 업로드하지 않는다.
