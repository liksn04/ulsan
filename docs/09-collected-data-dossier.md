# 09. 후속 연구 데이터 통합 조사철 (Data Dossier)

이 문서는 PR #7(2026-11-07 병합)에서 추가한 조사 메모다. 선사 취락, 고대 하곡현, 조선 굴화역·굴화원, 1914년 이전 4개 마을, 37개 미세지명과 관련해 **조사철 작성자가 찾았다고 기재한** 관찬 지리지 구절, 호적, 발굴보고서 서지, 지번·주소 대응을 모았다.

## 문서 지위 (2026-11-08 정리)

- PR #7에는 각 자료의 열람본, 면수, 열람일, 조회 기록이 없다. 이 문서의 원문 구절·인물·서지·좌표는 **원자료와 대조하기 전까지 확인된 사실로 인용하지 않는다.**
- 각 항목은 `data/sources.csv`(SRC-013~SRC-026)와 `data/claims.csv`(CL-013~CL-022)에 등록했다. 증거 상태는 대부분 `pending`이고, 근거가 없거나 기존 자료와 충돌하는 서술은 `disputed`로 두었다.
- 원안에서 결론을 앞질러 쓴 문장은 고쳤다. 원래 문장과 고친 이유는 [03. 정정 기록](03-toponymy-and-errata.md#pr-7-조사철-정리에-따른-정정-2026-11-08)에 남겼다. 원안 전문은 Git 이력(커밋 `779d168`)에서 볼 수 있다.

- SRC-001(2018)은 같은 변천을 "세종·예종: 굴화·장고암 → 정조: 장검리·굴화리 → 1894: 역리·장검리"로 적는다. 조사철의 1672·1699·1895 항목은 이와 연대가 다르거나 SRC-001에 없는 항목이므로 근거를 확인할 때까지 표를 인용하지 않는다.
- 장고암과 장검: 1469년 장고암리, 1672년 장검리가 각각 원문에서 확인되더라도 명칭이 바뀐 같은 취락인지는 별도 논증이 필요하다. CL-009 가설로 유지한다.
- 괴정의 유래: 조사철 원안은 "마을 복판 큰 홰나무(느티나무) 정자에서 유래한 참나무징이/참나무정이 槐亭으로 정착"이라고 적었다. 근거가 없고, SRC-001은 참나무 전승을 백천 각주에 둔다. 홰나무·느티나무·참나무를 한 문장에 섞은 것도 맞지 않는다. CL-022 `disputed`.

### 7.2 국가기록원 지적원도(1912~1918) — SRC-009, 미확보

- 법정동코드: `3171025924` (울주군 범서읍 굴화리). 조사철은 '행정동코드'라고 적었으나, 이 값은 CP-004 출처의 도로명주소 건물관리번호 앞 10자리와 같은 법정동코드다.
- 도엽: 울산군 범서면 굴화리 일원. 도엽 번호는 아직 식별하지 못했다.
- 작업 순서(계획):
  1. 도엽의 도곽 모서리와 도면에 표기된 측량 기준점을 기록한다. 조사철 원안의 "사구소삼각망 기준점"은 뜻이 불분명해 원도 확인 후 다시 쓴다.
  2. docs/04 GIS 단계 3의 기준대로 하천 합류부·능선·도로 접점 등 오래 유지된 지형지물을 제어점으로 고른다. 태화강·굴화천 합류부는 1910년대 이후 유로가 바뀌었을 수 있으므로 쓸 때 이동 가능성을 함께 기록한다.
