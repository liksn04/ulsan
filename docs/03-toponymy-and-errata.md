# 03. 굴화 지명 해석과 전사 대조 기록

## 굴화라는 말의 계승

- `屈阿火`(굴아화): 『삼국사기』가 설명하는 옛 이름.
- `河曲`(하곡): 신라 경덕왕 때 개칭했다고 기록된 지명; '강의 굽이'라는 지형 설명과 상응할 수 있다.
- `屈火`(굴화): 현재 굴화리의 표기.
- `屈佛`(굴불), `堀火`(굴화): 고려~조선 역참 계통의 표기 사례.
- 한자의 뜻을 그대로 이어 붙여 '불이 굽는 곳' 등으로 단정하지 않는다. 구불·구벌·굴아벌 계통 및 고대어 형태 재구는 **학설**로 구분한다.
- `굴아화촌`과 `하곡현`의 지리적 동일성 서술이 곧 현 관아·촌 중심 건물의 정확한 필지 비정을 뜻하지 않는다.

## 통합 이전 네 마을

2018년 지명집은 세종/예종: 굴화·장고암, 정조: 장검리·굴화리, 1894: 역리·장검리, 1911: 굴화·장검·백천·괴정, 1914 통합: 굴화리를 제시한다. **각 연대의 공식 문서 검증과 공간 경계의 확정은 미완료**이다.

- 장검(長劍/長劒)과 장고암(長古岩)의 관계는 명칭 유사성만으로 동일시 불가.
- 백천(栢川)은 '옛날 참나무가 무성하고 앞에 내(川)가 있다'는 지명집 각주에 근거. 한자 栢의 식물 종명과 구술 전승은 구별.
- 괴정(槐亭)은 물탕골/상아골의 1911년 귀속과 연결되지만 옛 마을 중심·경계 미확정.
- 수정(秀亭)과 괴정(槐亭)을 **같은 마을로 확정하지 않는다**. 지명집 각주 18은 수정(秀亭), 별도의 인용 지명 水亭坪(槐亭洞)이 있음. '수정(槐亭)'이라는 단일 표기가 직접 원문에서 확인된 것처럼 서술하지 않는다.

## 이름만 남은 1911 인용 4건

지명집 지면에서는 골짜기 명단 말미에 `鳥川谷`(백천동)과 `佛堂谷`(장검동), 들판 명단 말미에 `道溫前坪`·`石巖前坪`(장검동)이 이어진다. 바로 앞의 허장골/홍골들과 일대일 대응한다고 단정할 근거가 없다. 데이터에서는 `unmatched_citation` 유형으로 독립 기록한다.

## 지명별 후속 검증 질문

2. 장고암(長古岩)·장검(長劍)은 실제 같은 마을을 가리키는가?
3. 굴화의 굴아화·굴불 표기가 지역 주민 발음의 연속성인가, 후대 한자 차용의 결과인가?
4. `원내골`의 院內가 실제 굴화원 위치를 가리키는가, 아니면 후대 민간어원인가?
5. 구영리 187번지의 굴안골이 1911년 굴화 계통 자료에 수록된 이유는 무엇인가?
