# 울산 굴화리 역사·옛 지명 복원 연구

> **Ulsan Historical Toponymy & Landscape Reconstruction**  
> 조사 시작: 2026-11-07 · 연구 상태: 자료 대조·1차 공간복원 · 공개 연구용

## 목적

울산광역시 울주군 범서읍 **굴화리**와 인접한 태화강 생활권의 지명, 마을, 교통·행정사, 발굴 유적, 근현대 경관 변화를 **원자료-주장-좌표-지도**로 연결한다. 최종 산출물은 출처를 추적할 수 있는 지명 데이터베이스, 시대별 역사 지도, 검증 가능한 지역사 보고서이다.

**이 저장소는 역사적 사실을 확정하는 지도나 문화유산 지정 데이터가 아니다.** 1911년 원본 『조선지지자료』, 일제강점기 지적원도, 개별 발굴보고서의 정밀 대조가 남아 있다.

## 프로젝트가 출발한 질문

1. ‘굴화(屈火)’는 왜 이런 이름으로 불리며 ‘굴아화(屈阿火)·하곡(河曲)·굴불(屈佛)’과 어떤 관계인가?
2. 1914년 통합 이전의 **굴화·장검·백천·괴정** 네 옛 마을은 어디에 있었는가?
3. 골짜기 21개, 들판 8개, 별도 1911년 지명 인용 4개의 위치를 어디까지 복원할 수 있는가?
4. 굴아화현/하곡현, 고려·조선시대 굴화역(굴불역) 및 굴화원은 어디에 있었는가?
5. 청동기 취락에서 근현대 도시화까지 태화강과 도로·농지가 어떻게 변했는가?

## 데이터 작업

Python 3.10+ 표준 라이브러리로 검증·변환 가능. 외부 패키지 설치 불필요.

```bash
python scripts/validate_data.py
python scripts/export_geojson.py --output outputs/control_points.geojson
python -m unittest discover -s tests -v
```

**좌표 안내:** `data/control_points.csv`의 점들은 현대 주소·정류장·시설 기준점이다. 옛 마을의 중심지·경계 또는 유적지 위치를 확정하지 않는다. `data/toponyms.csv`의 좌표가 없는 지명은 임의로 점을 생성하지 않는다.

## 운영 원칙

- **출처별 원문성**: 1911년 기록을 2018년 자료집에서 재인용했다면, 1차 사료를 직접 열람한 것처럼 쓰지 않는다.
- **정정 이력 보존**: 옛 답변/엑셀과 원문이 다르면 [정정사항](docs/03-toponymy-and-errata.md)에 남긴다.
- **사실과 가설 분리**: 기록된 표기·주소와 어원설·고대 관아 비정은 별도로 관리한다.
- **좌표와 영역 분리**: 지번 대표점과 골짜기/역촌 전체 경계를 혼용하지 않는다.
- **시대 분리**: 청동기 주거지가 동시에 존속한 취락 규모라고 가정하지 않는다.
- **출처·저작권 준수**: 원문 PDF·지도·사진을 무단 재배포하지 않고 URL, 열람 기록과 짧은 사실 요약을 우선 제공한다.
- **개인정보 최소화**: 살아 있는 주민의 성명·연락처·구술 녹음은 동의 없이 공개하지 않는다.

## 저장소의 현재 한계

2026-11-07 대화에서 작성한 1차 엑셀을 **작업 초안**으로 삼되, 2018년 자료집의 실제 PDF 지면(13~14쪽)과 다시 대조해 전사 오류를 정정했다. 아직 1911년 필사본, 근대 지적원도 이미지, 원본 GIS 레이어, 현장 답사 결과는 등록하지 않았다. 위치 데이터는 행정적 또는 학술적 확정 정보를 의미하지 않는다.

공개 저장소이므로 누구나 주장과 출처를 검증할 수 있도록 연구 과정과 불확실성을 함께 남긴다.
